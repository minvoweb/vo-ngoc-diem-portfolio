# Website portfolio – Võ Ngọc Diễm

Cấu trúc: index / about / education / experience / skills / contact (.html), assets/css, assets/js, assets/images, assets/files.

## Chạy trên máy
Web một trang cuộn (one-page). Giải nén, bấm đúp `index.html` (hoặc mở thư mục bằng VS Code + Live Server).

## Đưa lên GitHub Pages
1. Tạo repo mới trên github.com (ví dụ `portfolio`).
2. Add file → Upload files, kéo TOÀN BỘ nội dung thư mục này lên (giữ nguyên thư mục assets), bấm Commit.
3. Settings → Pages → Branch: main, thư mục /root → Save.
4. Chờ 1–2 phút, web có tại https://<tên-github>.github.io/<tên-repo>/

## Lưu ý
- assets/files/ có catalog (giá sỉ, giá thanh lý, SĐT đồng nghiệp) và dashboard đối thủ của công ty: hãy xin phép công ty trước khi đăng công khai, hoặc xóa file và thẻ "Sản phẩm công việc" trong experience.html.
- Phần thông tin chưa có (SĐT, GPA, kết quả cụ thể của thực tập) hãy bổ sung sau.
