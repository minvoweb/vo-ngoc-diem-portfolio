# Portfolio – Võ Ngọc Diễm

Web một trang (one-page). Mở `index.html` để xem trên máy.

## Đưa lên GitHub Pages
1. Giải nén file zip.
2. Tạo repo mới trên github.com (ví dụ `portfolio`).
3. Add file → Upload files, kéo TOÀN BỘ nội dung vừa giải nén (gồm `index.html` và thư mục `assets`) lên, bấm Commit.
4. Settings → Pages → Branch: main, thư mục /(root) → Save.
5. Chờ 1–2 phút, web có tại https://<tên-github>.github.io/<tên-repo>/

## Cấu trúc
- index.html
- assets/css/style.css, assets/js/main.js
- assets/images/ (ảnh + favicon)
- assets/files/ (CV, catalog, dashboard)

## Lưu ý
- `assets/files/` có catalog (giá sỉ, giá thanh lý, SĐT đồng nghiệp) và dashboard đối thủ của công ty: xin phép công ty trước khi đăng công khai, hoặc xóa file và hai thẻ "Sản phẩm công việc" trong index.html.
- Ảnh nào chưa có trong `assets/images/` thì tự ẩn; bỏ ảnh vào đúng tên là hiện lại.
